# Project workflow

- Product name: brain off. Repository: https://github.com/guoxinyi0811/brain-off.
- Approved visual direction: minimal monochrome UI matching a flat refrigerator drawn with black outlines. Use white space, black lines and restrained gray. Avoid gradients, shadows, decorative cards, slogans and redundant copy. Keep controls, dialogs and food lists consistent with this line-art style.
- The owner has authorized uploading project files and syncing each completed, verified project update to this repository. Use the GitHub connector or Git CLI when available; browser upload is a fallback.
- Run `npm test` and `npm run typecheck` for domain/code updates before syncing. Inspect changes and exclude node_modules, secrets, personal files and scratch artifacts.
- Keep user requirements, approved decisions, assistant proposals and unresolved questions distinct. Do not expand milestone scope implicitly.
- Cloud synchronization is required eventually, but is deferred beyond milestone 1.
- Website deployment, GitHub Releases and public visibility changes require separate authorization.
